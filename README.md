# Boteco RWX Site

Site oficial do Boteco RWX.

Estado inicial do projeto. O desenvolvimento ativo acontece em branches `dev/*` e a `main` permanece como linha estável.

## Princípio de engenharia

**Magia é permitida. Desperdício não.**

Aplicamos a filosofia Carmack: simplicidade, modularidade, performance medida e complexidade somente quando houver necessidade real.
